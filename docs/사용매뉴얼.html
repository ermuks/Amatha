1 로그인

회사 ERP 아이디와 비밀번호를 입력하고 로그인합니다.

환경설정에서 자동 로그인을 켜 두면 다음부터는 이 화면 없이 바로 시작합니다.

2 미작성 목록

로그인하면 작성하지 않은 출장·휴일근무 보고서와 대체휴가 요청서를 한 화면에 모아 보여 줍니다.

잠시 알림을 쉬고 싶을 때

2시간 동안 알리지 않음을 체크하세요. 항목은 목록에 남고, 그 항목의 알림만 잠시 멈춥니다.

체크 해제 또는 2시간 경과 → 다음 주기부터 다시 알림

더 이상 표시하고 싶지 않을 때

항목의 삭제를 누르세요. 그 항목은 목록과 알림에서 영구 제외되며, 다시 실행해도 유지됩니다.

앱의 목록에서만 제외 · ERP 문서는 그대로 유지

상태 칩으로 지금 써야 하는지 알 수 있습니다. 작성 필요(기간이 끝남) · 진행 중 · 예정 · 요청서 없음/시간 오류(대체휴가). 2시간 알림 중지는 새로고침·재시작으로 연장되지 않습니다.

3 신청서 확인

미작성 목록의 항목을 누르면 그 기간에 연결된 신청서 원문이 신청서 보기 창에 열립니다. 출장 기간·출장지·목적을 확인할 때 쓰세요.

이 프로그램은 보고서를 대신 작성하지 않습니다. 작성하지 않은 보고서를 찾아 알려 주기만 하므로, 보고서는 ERP에서 직접 작성·상신해 주세요. 상신한 뒤 새로고침하면 목록에서 빠집니다.

연결된 신청서를 찾지 못한 항목이나 대체휴가 항목은 창 대신 화면 오른쪽 아래에 안내가 잠깐 표시됩니다.

4 메일

왼쪽 메뉴의 메일을 누르면 받은메일함이 열립니다. 왼쪽에 목록, 오른쪽에 본문이 함께 보여서 목록으로 돌아가지 않고 다른 메일을 바로 열 수 있습니다.

목록 · 검색

최신순 100건씩 보여 주며 이전/다음으로 페이지를 넘깁니다. 안 읽은 메일은 보라색 점과 굵은 글씨로 표시됩니다. 검색 상자와 전체 · 안 읽음 · 첨부파일 필터는 지금 페이지 안에서 바로 거릅니다.

메일을 누르거나 ↑ ↓ 키로 고르면 오른쪽에 본문이 열림

첨부파일

본문 아래의 다운로드로 파일마다 저장 위치를 고르거나, 여러 개면 모두 다운로드로 폴더를 한 번만 고르세요. 같은 이름은 번호를 붙여 저장합니다. 받는 중에는 다운로드 취소로 멈출 수 있습니다.

받는 동안은 목록이 잠깁니다 (다운로드가 끊기지 않게)

가운데 구분선을 끌면 목록 폭을 바꿀 수 있습니다. 본문의 외부 이미지는 자동으로 표시되고, 웹 링크는 기본 브라우저로 열립니다. 닫기를 누르면 본문만 닫히고 목록 선택은 그대로 남습니다.

5 메뉴 · 환경설정

왼쪽 메뉴는 항상 보입니다. 위쪽은 화면 이동(미작성 목록 · 메일 · 사용자 매뉴얼), 아래쪽은 업데이트 확인 · 환경설정 · 로그아웃 · 종료하기입니다. 이 매뉴얼도 같은 창 안에서 열립니다.

스위치와 숫자를 바꾸면 바로 저장됩니다. 따로 저장하거나 닫는 버튼은 없고, 다른 메뉴로 이동하면 됩니다.

6 트레이 · 종료

창의 X를 누르면 꺼지지 않고 화면 오른쪽 아래 트레이로 들어갑니다. 트레이 아이콘을 누르면 메뉴가 열립니다.

완전히 끄려면 트레이 메뉴나 왼쪽 메뉴의 종료하기를 누르세요. 확인 창에서 예를 고르면 프로그램이 꺼집니다.

7 알림

목록에는 보여도, Windows 알림은 기간이 끝난 뒤에만 갑니다.

출장·휴일근무 전알림 없음
진행 중알림 없음
끝난 뒤 미작성알림

프로그램 안의 안내(업데이트 결과, 저장 실패 등)는 창 오른쪽 아래에 잠깐 떴다 사라집니다. 처음 6초 동안 보이고, 글이 길면 최대 20초까지 늘어납니다. 마우스를 올려 두면 멈추고, 오른쪽 ×를 누르면 바로 닫힙니다.

8 업데이트

새 버전이 나오면 왼쪽 메뉴 맨 아래에 새 버전이 있습니다 안내가 나타납니다. 누르면 업데이트 확인 창이 열립니다.

체크하면 · 조용히 업데이트

지금 설치된 폴더에 자동으로 업데이트합니다. 경로 선택과 설치 완료 화면을 거치지 않고, 끝나면 트레이로 다시 실행됩니다.

체크하지 않으면 · 일반 설치

설치 화면이 열립니다. 설치 폴더를 고르고 설치한 뒤, 완료 화면에서 실행 여부를 고릅니다.

  1. 조용히 업데이트하기를 체크하고 예를 누릅니다.
  2. Windows 관리자 권한 확인 창이 나타나면 허용합니다.
  3. 업데이트가 끝나면 트레이 아이콘에서 창을 다시 열 수 있습니다.

조용한 업데이트 중에도 Windows 관리자 권한 확인은 필요하며, 설치에 실패하면 오류 안내가 표시됩니다. 왼쪽 메뉴의 업데이트 확인으로 언제든 직접 확인할 수 있습니다.
