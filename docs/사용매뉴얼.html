신청은 했는데 보고서를 안 쓴 건을 찾아 알려 줍니다.

1 로그인

회사 ERP 아이디와 비밀번호를 입력하고 로그인합니다.

2 미작성 목록

카드를 누르면 기존에 작성한 신청서가 내장 웹뷰어에 표시됩니다.

잠시 알림을 쉬고 싶을 때

2시간 동안 알리지 않음을 체크하세요. 카드는 목록에 남고, 해당 항목의 알림만 잠시 멈춥니다.

체크 해제 또는 2시간 경과 → 다음 주기부터 다시 알림

더 이상 표시하고 싶지 않을 때

카드의 삭제를 누르세요. 해당 항목은 목록과 알림에서 영구 제외되며, 재시작해도 유지됩니다.

앱의 목록에서만 제외 · ERP 문서는 그대로 유지

2시간 알림 중지는 새로고침·재시작으로 연장되지 않습니다. 삭제는 해당 종류와 기간의 항목에 적용되며, 다른 날짜의 새 항목은 계속 표시됩니다.

3 신청서 확인 · 보고서 작성

내장 웹뷰어에서 기존 신청서를 확인한 뒤, ERP에서 보고서를 작성·상신하세요.

카드 클릭은 신청서 원문 조회입니다. 연결된 신청서가 없는 경우에는 ERP에서 확인하라는 안내가 표시됩니다. 아래는 ERP에서 보고서를 작성할 때의 참고 화면입니다.

4 메뉴 · 환경설정

왼쪽 ☰ 을 누르면 설정, 로그아웃, 종료가 나옵니다.

이메일 목록 · 받은 메일 확인

메뉴의 이메일 목록을 누르면 현재 로그인한 계정의 받은메일함이 열립니다. 제목·보낸 사람·받은 시각·첨부 여부를 볼 수 있으며, 안 읽은 메일은 강조 표시됩니다.

최신순 100건씩 표시 · 이전/다음으로 이동 · 새로고침으로 최신 목록 조회

메일을 클릭하거나 선택 후 Enter를 누르면 내장 웹뷰어에 본문이 열립니다. HTML이 없는 메일은 일반 텍스트로 표시됩니다.

이미지 표시를 누르면 외부 이미지를 불러옵니다. 본문의 웹 링크는 기본 브라우저로 열리며, 첨부파일 다운로드는 ERP에서 이용해 주세요.

5 트레이 · 종료

창을 닫으면 오른쪽 아래 트레이로 갑니다. 아이콘을 누르면 메뉴가 열립니다.

종료하기를 누르면 확인 창이 뜹니다. 예를 고르면 완전히 꺼집니다.

6 알림이 가는 때

목록에는 보여도, 알림은 기간이 끝난 뒤에만 갑니다.

출장·휴일근무 전알림 없음
진행 중알림 없음
끝난 뒤 미작성알림

7 업데이트

창 아래의 새 버전 안내를 누르면 업데이트 확인 창이 열립니다.

체크하면 · 조용히 업데이트

현재 설치된 폴더에 자동으로 업데이트합니다. 경로 선택과 설치 완료 화면을 거치지 않고, 완료되면 트레이로 다시 실행됩니다.

체크하지 않으면 · 일반 설치

기존 설치 화면이 열립니다. 설치 폴더를 선택하고 설치를 진행한 뒤, 완료 화면에서 실행 여부를 고릅니다.

  1. 조용히 업데이트하기를 체크하고 예를 누릅니다.
  2. Windows 관리자 권한 확인 창이 나타나면 허용합니다.
  3. 업데이트가 끝나면 트레이 아이콘에서 창을 다시 열 수 있습니다.

체크박스는 1.8.0부터 표시됩니다. 조용한 업데이트 중에도 Windows 관리자 권한 확인은 필요하며, 설치에 실패하면 오류 안내가 표시됩니다.
